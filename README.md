# hongzhuointernet
# 鸿桌互联

通过蓝牙技术实现设备之间的通知信息同步

## 蓝牙通知同步

1. 在两台 Android 17 设备上安装并打开应用，分别授予通知访问权限和蓝牙连接权限。
2. 先在系统蓝牙设置中完成两台设备的配对。
3. 在应用「设置」中分别绑定对方设备；可绑定多台设备，绑定后应用会通过加密的蓝牙 RFCOMM 连接自动重连并双向同步通知。

同步内容包括通知标题、正文、来源应用和移除状态；通知数据只保存在应用运行时内存中。媒体通知不会同步封面、播放控制或 PendingIntent。解除绑定会停止同步。

通知列表按本机和同步设备分组。绑定的多台设备各自独立连接和自动重连，通知和自定义通知栏消息会发送到所有已绑定设备；接收设备需要授予通知权限，消息才会显示在其通知栏。
